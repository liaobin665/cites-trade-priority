# 方法说明

这一页记录分析中容易被压缩掉的选择：标签规则、候选池、60 个特征，以及用来区分
“真的排序增益”和“照搬上年名单”的几项检查。

## 1. 单元与口径

一条观测是**出口国 × 物种 × 年**。贸易量取出口方报告、直接出口、计件单位的
`Quantity` 之和；单位缺失的记录保留，其他单位不折算。

同时保留两个量：

- `v_wild`：`Source = W` 的记录。标签与候选池用它。
- `v_cnt`：全部来源代码。特征用它，并配合来源占比（`src_W` … `src_U`）与
  `v_wild_share`。

两者都留是有意的：只用野生的标签回答“哪条野生流要激增”；只用野生的特征矩阵会丢掉
“同一个出口国也在出口人工繁殖个体”这一事实，而它会改变一次数量跳升的含义。来源占比
让模型能用上这层背景，又不把两类贸易混为一谈。

## 2. 标签

对出口国 `c`、物种 `u`、标签年 `T`：

```
M(c,u,T) = (1/5) * sum_{k=1..5} V_wild(c,u,T-k)
```

满足任一条件即为正例：

```
本国激增：V_wild(c,u,T) > 4 * M(c,u,T)  且  M(c,u,T) >= 100
全球激增：V_wild(u,T)   > 4 * M_world(u,T) 且
          M_world(u,T) >= 100 且
          V_wild(c,u,T) / V_wild(u,T) >= 0.10
```

两条对应 CITES 重大贸易审查（Review of Significant Trade）里的两条 sharp increase
判据。阈值（4 倍、均值不低于 100、份额 10%）在建模前固定；图集中的敏感性分析报告
3 倍与 5 倍的结果。

零贸易年与未报告年都按零进入均值，分母固定为 5。这样有意放宽：要求连续五年有贸易，
会把“刚出现”的流系统性排除，而它们正是名单要覆盖的对象。代价是记录稀疏、基数小的
组合可能因一次恢复性贸易被放大。

## 3. 候选池

标签年 `T` 的候选，是 `T-3 … T-1` 至少有一年野生来源记录的单元。五年窗口只用于
算均值，不要求每年都有贸易。2016–2024 年测试窗口中，**每年候选 3,129–4,136 个**。

## 4. 60 个特征

全部截至 `t = T-1`，只使用 ≤ `t` 的年份。

### 4.1 贸易史（15）

| 特征 | 定义 |
|---|---|
| `v_log1p` | log(1 + 当年贸易量) |
| `v_lag2_log1p` | log(1 + 前两年贸易量) |
| `active5` | `t-4 … t` 中有贸易的年数 |
| `recency` | 距最近一次正贸易的年数（从未则为 25） |
| `cv5` | `t-4 … t` 的变异系数 |
| `slope5` | `t-4 … t` 的 OLS 斜率，按均值归一 |
| `max_over_mean5` | `t-4 … t` 的最大值 / 均值 |
| `zero_years5` | 5 − `active5` |
| `log_records` | log(1 + 记录条数) |
| `qty_per_record` | 贸易量 / 记录条数 |
| `last_share5` | 当年贸易量 / 五年合计 |
| `v_allunit_ratio` | 全单位量 / 计件单位量 |
| `v_lag3_log1p` | log(1 + 前三年贸易量) |
| `v_sum_lag3_log1p` | log(1 + `t-3 … t-1` 合计) |
| `v_std_log` | log(1 + `t-4 … t` 标准差) |

### 4.2 网络位置（18）

| 特征 | 定义 |
|---|---|
| `deg_exp` | 出口国交易的物种数 |
| `deg_sp` | 该物种的出口国数 |
| `share_global` | 单元量 / 该物种全球量 |
| `hhi_sp` | 该物种在出口国间的集中度 |
| `peer_vol_log` | log(1 + 该物种除本单元外的量) |
| `peer_growth` | 同伴量 / 同伴五年均值 |
| `exp_total_log` | log(1 + 出口国总量) |
| `exp_entropy` | 出口国物种组合的熵 |
| `exp_growth` | 出口国总量 / 五年均值 |
| `jac_max` | 与同伴出口国的最大 Jaccard 重叠 |
| `jac_mean` | 平均 Jaccard 重叠 |
| `aa_peer` | 国家投影上的 Adamic–Adar 同伴分 |
| `genus_countries` | 交易该属的出口国数 |
| `genus_vol_share` | 单元量 / 属总量 |
| `partner_country_n` | 至少共享一个物种的国家数 |
| `growth_rank_sp` | 物种内增长的百分位排名 |
| `deg_exp_chg` | 出口国度数的同比变化 |
| `sp_growth` | 物种总量 / 五年均值 |

### 4.3 贸易形态与分类（27）

| 特征 | 定义 |
|---|---|
| `term_entropy` | 产品形态组合的熵 |
| `live_share` | 活体量 / 贸易量 |
| `top_term_share` | 最大产品形态占比 |
| `terms_n` | 不同 term 数 |
| `importers_n` | 不同进口国数 |
| `top_importer_share` | 最大进口国占比 |
| `origin_n` | 不同原产国数 |
| `src_W` … `src_U` | 各来源代码占比（W、C、F、R、D、A、U） |
| `v_wild_share` | 野生量 / 总量 |
| `p_T`、`p_P`、`p_H` | 用途代码 T、P、H 的占比 |
| `reexport_share` | 再出口量 /（贸易量 + 再出口量） |
| `appendix_code` | I=3、II=2、III=1、N=0、未知=−1 |
| `class_code`、`order_code`、`family_code`、`genus_code` | 分类学频次编码 |
| `is_spp` | 名称含 “spp.” |
| `is_hybrid` | 名称含 “hybrid”“cultivar” 或 “x” |
| `taxon_n_tokens` | 学名中的词数 |

规则状态类特征（滞后规则标记、标签比值本身、五年均值水平）被有意排除：它们会让模型
直接从规则里读答案，而不是学习可迁移的形态。

## 5. 模型与协议

- LightGBM 二分类，300 轮，学习率 0.05，31 叶，叶最小样本 50，特征与行采样 0.8。
- 类别权重 = 负样本数 / 正样本数。
- 三个种子（0/1/2），逐年表取种子均值。
- 测试年 `T`：用 2005 … `T-1` 训练，预测 `T`，每年单独重训。
- 不在测试年上调参。

## 6. 指标与基线

每年取前 100：

- AP：整份名单的平均精度；
- precision@100：前 100 中的正例比例；
- recall@100：前 100 覆盖当年正例的比例；
- hits@100：前 100 中的正例数。

事后基线只用上一年的年度汇总：

1. **persistence**：照搬上年正例名单；
2. **growth**：按 `V(T-1) / M(T-1)` 排序；
3. **volume**：按 `V(T-1)` 排序。

某年的“最强基线”是三者中该指标最好的那一条。persistence 与 volume 的同分随机
排序取 20 次平均。

## 7. 检查

- **新案通道**：从测试池中剔除上年正例后重新排序。persistence 按定义退化为随机；
  只会照搬上年的模型无法通过。
- **名单重叠**：今年前 100 与上年前 100 的重叠，以及上年正例中今年仍为正例的比例。
- **标签打乱**：把训练标签随机打乱后重训，在真实标签上评价；性能应回落到正例比例附近。
- **SHAP**：每个特征的 TreeSHAP 绝对值，九个测试年平均后按特征组汇总。
